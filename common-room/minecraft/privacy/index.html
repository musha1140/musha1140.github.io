Privacy for the server

This covers the Minecraft server gate on this site, the Discord application (“GSL”) behind it, and the game server itself. It is written for one purpose: deciding who may join a private Minecraft server, and letting them in. Effective 5 November 2026.

what is collected, and why

  • Discord identity — your user id, username and avatar, read when you log in with Discord (scope identify), plus your roles in the GASLIGHTING Discord and the dates your account was created and joined. Used to check that you are a verified member and to show the host who is asking.
  • Minecraft names — the Java username and/or Xbox gamertag you type. The Java name is looked up on Mojang’s public API to get its id; the gamertag is looked up on GeyserMC’s public API to get its Xbox id and whether your Java and Xbox accounts are linked. Used to put you on the whitelist.
  • An email address — only so the host can answer you. It is shown to the host inside Discord. Nothing is sent to it by any automated system.
  • Your message — the few lines you write about who you are.
  • Game data — once you play, the Minecraft server keeps the usual things a Minecraft server keeps: your player data, position and inventory, join and leave times, your IP address in its log, and a ledger of block and container actions used for moderation.

where it lives

On the machine that runs the game server, in plain files, readable by the host. Application cards (the request you send) live in a private channel of the GASLIGHTING Discord that only the host and the bot can see. Nightly backups of the world and these files are copied to private cloud storage and kept for 30 days.

cookies

Logging in sets one cookie, gl_session, on gas-lighting.com for 14 days. It is signed, HttpOnly and used only to recognise you on this page and at the gate’s API. A second one, gl_oauth, lives for ten minutes during the Discord login itself. No analytics or advertising cookies are set by this feature. “Not you?” clears the session.

who else sees it

Discord (login, roles, the request card and the DM with join steps); Mojang and GeyserMC (the public lookups above, which receive only the name you typed); the hosting providers that run the server and the backups. Nothing is sold, shared for advertising, or sent anywhere else.

how long

Your whitelist record is removed when you lose the role, leave the Discord, are removed from it, or ask. Game logs rotate; backups age out after 30 days. A declined application is kept only as the card in the private Discord channel.

your choices

Ask the host in the Discord to see, correct or erase what is kept about you. You can revoke the app’s access to your Discord account at any time under Discord’s Authorized Apps settings.

age

The server is for adults. If you are under 18, do not apply.

contact

Through the GASLIGHTING Discord. See also the terms.
