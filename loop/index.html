Gas-Lighting · The Loop

The machine listens to itself.

No microphone, no key, no server. The song is the initial sound and the machine already knows every note it plays, so it transcribes itself honestly: MIDI pitch and ASCII share the same 7-bit space (0–127), which makes every note a character. The characters relay through the Morse dot; the note flow drives the valve's dual-set-point regulator, so the song's cadence becomes the pressure curve; and each time the needle settles in the green, the transcript is digested into an MDTGF initiator seed.

The speech leg, a real transcriptor listening to spoken sound and relaying it through the same socket, is deliberately deferred to the always-on GSL node (see the whitepapers' phases).
