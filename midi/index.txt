d:T15e8,<p>A single page cipher toy where <strong>the song is the key</strong>. Type a message (or drop
any file), pick a MIDI song, and watch the bytes get XORed against a keystream
derived from that song&#39;s notes. The result plays out on a 64 cell grid with a
true binary dump underneath, then collapses into a shareable QR code.</p>
<p>Live at <strong><a href="https://gas-lighting.com/GS/">gas-lighting.com/GS</a></strong>.</p>
<h2>How it works</h2>
<ul>
<li><strong>The keystream.</strong> A MIDI file is a constant, so its parsed note sequence is a
constant too. Every note contributes three bytes (its number, velocity, and
ticks) into a deterministic keystream.</li>
<li><strong>The chop.</strong> Your input bytes are XORed against that keystream, cycling
circularly when the lengths differ. XOR twice with the same song and you get
the original back, bit for bit. It is lossless.</li>
<li><strong>The seal.</strong> An AES-256-GCM layer (Web Crypto, PBKDF2) wraps the payload so a
<code>.slayy</code> file or a share link can be decompiled with integrity, and the
decompiler re-derives the keystream from the song to prove the bits check out.
The passphrase lives in the page source. This is art, not security.</li>
<li><strong>The dump.</strong> The binary shown below the grid is not decorative. It is the real
XOR output, revealed in order and driven by the Tone.js transport clock as the
song plays.</li>
</ul>
<h2>Features</h2>
<ul>
<li>Message, file, image, or code input. Bytes are bytes.</li>
<li>64 cell gate grid: tap to flip, drag to paint, hold to clear.</li>
<li>Real time binary dump driven by the transport, with a reshape control that
re-renders the same local data as a Perlin bloom field.</li>
<li>Syzygy QR sharing. A finished dump becomes an art QR (tap for the scannable
black on white form, hold to save a PNG). Scanning a share link replays the
decryption: the QR breaks down through the binary and the 64 cells spell the
message out.</li>
<li><code>.slayy</code> download and decompile with a keystream cross check.</li>
<li>A &quot;how it works&quot; slide over that includes a URL to QR tool and a zero width
method (see below).</li>
<li>Works with touch, pen, and mouse. iOS safe, no zoom on focus, reduced motion
honored.</li>
</ul>
<h2>Zero width messaging</h2>
<p>The app can hide a share link inside invisible Unicode characters so it rides
along in ordinary text. The deeper tool and write up live in a separate repo:
<strong><a href="https://github.com/musha1140/steganographr">steganographr</a></strong>.</p>
<p>Only Tailwind loads eagerly. Tone, the MIDI parser, and the QR library are lazy
loaded on first use, so the initial page is light.</p>
